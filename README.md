# CommonUI实战项目

## 项目介绍

本仓库的内容主要是作者学习完**CommonUI**插件以后的实战案例。

## 核心内容

1. **主要用到的类：**
   - UCommonActivatableWidget Common激活控件
   - UCommonButtonBase Common按钮基类
   - UCommonTextBlock Common文本块
   - UCommonTabListWidgetBase Common标签列表控件
   - UCommonListView Common列表视图
2. **代码实现**：
   - UCommonUI 插件功能基础实现
   - 自定义的数据对象应用

## 适合人群

- UEC++开发者。
- 常设计UI的开发人员。
- 2D游戏开发者。
